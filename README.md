# Huincha · actualizaciones

Este repositorio solo contiene la app Huincha ya armada para que se actualice desde el teléfono, con el botón **Actualizar**. El código fuente es privado.

- `huincha3/version.json`: número de la última versión.
- `huincha3/web.zip`: actualización que instala la app sola.
- `huincha3/huincha3.apk`: instalador completo para Android ([descargar](https://github.com/aaroncontrerasfarah/huincha-actualizaciones/raw/main/huincha3/huincha3.apk)).
